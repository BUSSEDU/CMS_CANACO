# CMS Canaco

## Descripción

CMS Canaco es un proyecto web desarrollado con Django para ayudar a Canaco a administrar su información y publicar noticias de una manera fácil y organizada.

## Tecnologías utilizadas

* **Python 3:** utilizado para programar el proyecto.
* **Django 4.2:** framework utilizado para desarrollar la aplicación web.
* **SQLite:** base de datos utilizada para almacenar la información.
* **HTML5:** utilizado para crear la estructura de las páginas.
* **CSS3:** utilizado para darle diseño y estilo a la página.
* **Bootstrap 5:** utilizado para mejorar la apariencia de la página.

## Estructura del proyecto

El proyecto cuenta principalmente con las siguientes partes:

* **canaco:** contiene la configuración principal del proyecto Django.
* **home:** aplicación encargada de las funciones principales de la página.
* **manage.py:** archivo utilizado para ejecutar los comandos de Django.
* **db.sqlite3:** base de datos utilizada para guardar la información del proyecto.
