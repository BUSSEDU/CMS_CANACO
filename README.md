Es un proyecto web realizado con Django para ayudar a Canaco a administrar su información y publicar noticias de una manera más fácil y organizada.
Python 3: se utilizó para programar el proyecto.
Django 4.2: se utilizó para desarrollar la página web.
MySQL / XAMPP: para guardar y administrar los datos.
Bootstrap 5: para darle diseño y hacer que la página se adapte a diferentes dispositivos.
HTML5: para crear la estructura de las páginas.
CSS3: para darle estilo y mejorar la apariencia de la página.
